# Beyond Temptation (React Rebuild)

A premium, motion-heavy restaurant website built with React, TypeScript, and Tailwind CSS.

## Project Setup

### 1. Install Dependencies
This will automatically generate your `package-lock.json` file and install all required packages.

```bash
npm install
```

### 2. Start Development Server
Runs the app in development mode. Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

```bash
npm run dev
```

### 3. Build for Production
Builds the app for production to the `dist` folder.

```bash
npm run build
```

## Tech Stack

-   **Core**: React, TypeScript, Vite
-   **Styling**: Tailwind CSS (Utility-first)
-   **Motion**: Framer Motion
-   **Icons**: Lucide React
-   **Theme**: Signature Yellow (`#FFD000`) & Deep Black (`#050505`)

## Structure

-   `src/components/ui`: Reusable UI primitives (Buttons, Cards).
-   `src/components/sections`: Page-specific sections (Hero, About, Menu).
-   `src/styles`: Global styles and Tailwind configuration.
